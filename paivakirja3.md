# Oppimispäiväkirja: Git projektissa

__Mitä hyötyä voisi olla versionhallinnasta, jos kehität projektia yksin?__

Sen avulla voi seurata tehtyjä muutoksia ja palata aiempaan versioon jos jokin menee pieleen tai muutoksista ei pidetä. Sen avulla voidaan myös luoda omia haaroja, joiden kautta voidaan kokeilla uusia ominaisuuksia koskematta pääversioon.

__Mitä hyötyä voisi olla versionhallinnasta, jos projektissa on useita kehittäjiä?__

Usean henkilön projekteissa versionhallinta helpottuu, sillä jokainen voi tehdä muutoksiaan omiin haaroihinsa, ja muutokset voidaan yhdistää myöhemmin yhteiseen versioon. Sen avulla voidaan myös helposti selvittää virheitä, sillä nähdään kuka on tehnyt mitäkin muutoksia ja milloin.

__Miten järjestäisit projektitiimin versionhallinnan 3-4 hengen ohjelmistoprojektikurssilla? Laadi tiimiläisille lyhyt ohje, miten projektissa toimitaan.__

Pitäisin projektissa yhteisen github repositorion. Siellä olisi main haara joka on projektin vakain ja huolletuin versio. Sitten jokainen tiimiläinen tekisi uudet muutokset ja ominaisuudet erillisissä haaroissa, joista myöhemmin yhdistettäisiin main haaraan.

Ohje tiimiläisille: Projektilla on yksi yhteinen github repositorio. Main haaraan ei tehdä suoraan mitään muutoksia, vaan jokainen tekee muutoksensa omassa haarassaan. Kun työ saadaan valmiiksi, tehdään pull request, jonka joku toinen tiimilisistä vielä tarkistaa ennen yhdistämistä. Kommenttien ja commit viestien täytyy olla selkeitä ja muutoksia tehdään pienissä osissa. Yhdistämisien jälkeen jokaisen täytyy päivittää oma paikallinen versionsa ajan tasalle.

__Kommenttini opintojaksosta, esim. sisällöstä, materiaalista, työmäärästä, hyödyllisyydestä, työmäärästä. Mitä toivoisit olevan enemmän, mitä vähemmän?__

Mielestäni materiaalia oli hyvä määrä ja se oli hyödyllistä. Vaikka teinkin kurssin lyhyellä ajalla, materiaalia ja tehtävän ohjeita oli helppo seurata ja noudattaa. Joissakin kohdissa joudun hetken miettimään mitä täytyy tehdä, mutta se on oletettavaa kun opiskelee uutta aihetta. Gitin perusasiat tulivat mielestäni hyvin esille. Tykkäsin kurssin tyylistä jossa aktiivisesti hyödynnettiin komentoja, eikä pelkästään luettu dioja ja tehty esim. jonkinlaista koetta.
